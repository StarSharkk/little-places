# 验证记录

验证对象：`npm run build` 生成的生产版本，通过 http://127.0.0.1:4176/ 提供预览。

## 已通过

- Vite 生产构建：30 modules，构建成功。
- 本机 Chrome / Playwright：1440 × 1000 桌面，390 × 844 手机视口。
- 总览共享一个 WebGL canvas，两栋真实 3D 建筑同时可见。

- 咖啡馆：模型门点击、门开合动画、模型招牌点击、菜单按钮、菜单关闭。
- 杂货铺：模型卷帘门点击和开合；四台扭蛋机；五张海报与商品没有包围盒相交。
- 两栋建筑的五种配色；杂货铺纹理图集随颜色更新；单栋状态保留和总览统一换色。
- 拖动旋转、滚轮平滑缩放、正面/侧面视角、默认视角精确恢复。
- 标签、自动旋转、空闲停止渲染、键盘标签页导航。
- 三种手机布局均无页面横向溢出；手机标签与两栋建筑操作按钮。
- 浏览器 pageerror 与 console error 均为 0。
